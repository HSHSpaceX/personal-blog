连接 GitHub

输入一个有本仓库写权限的 GitHub Token，即可在网页里编辑文章并发布。Token 只会保存在当前设备浏览器中。

如何创建 Token？
  1. 打开 Fine-grained Token 创建页。
  2. Token name 随意，例如 blog-admin；Expiration 建议选 90 天。
  3. Repository access 选择 Only select repositories，并勾选 personal-blog。
  4. Permissions 里把 Contents 设为 Read and write，其余保持默认。
  5. 生成后复制 Token，粘贴到上方输入框。
