连接 GitHub

输入有本仓库写权限的 GitHub Token 后即可发布。Token 仅保存在当前页面内存中；刷新、关闭或退出后需要重新输入。

如何创建 Token？

推荐：Fine-grained PAT

  1. 打开 Fine-grained Token 创建页。
  2. Repository access 只授权 HSHSpaceX/personal-blog。
  3. Permissions 中 Contents 必须选 Read and write。
  4. 设置合理到期时间，生成后只在当前页面输入 Token。

已有 Classic PAT 可暂时兼容，但不建议新建或长期使用。若提示 Resource not accessible，请检查目标仓库的 Contents 写权限。
