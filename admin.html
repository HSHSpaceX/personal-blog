连接 GitHub

输入一个有本仓库写权限的 GitHub Token，即可在网页里编辑文章并发布。Token 只会保存在当前设备浏览器中。

如何创建 Token？

方式一（推荐，最简单）：经典 Token

  1. 打开 经典 Token 创建页，已自动勾选 public_repo 权限。
  2. Expiration 建议 90 天或 No expiration，点击底部 Generate token。
  3. 复制以 ghp_ 开头的 Token，粘贴到上方输入框。

方式二（更安全）：Fine-grained Token

  1. 打开 Fine-grained Token 创建页。
  2. Repository access 只勾选 personal-blog。
  3. Permissions 中 Contents 必须选 Read and write。

如果保存或删除时提示 Resource not accessible，说明 Token 没有写权限，按上面任一方式重新生成后，退出并重新连接即可。
