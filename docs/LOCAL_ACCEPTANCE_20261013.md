- 文章沿用旧编辑器布局：标题、返回、折叠设置、预览、受控 HTML 源码、格式工具栏、公式和光标插入资源。仅接受安全结构，非法源码明确报错。分类取归档九类，服务端同步约束；旧版本保留，重编时明确转换。slug/首次发表身份由服务端保持，不恢复 PAT。
- 动态原页文字框、资源中心图片/视频、预览、草稿、提交、本人修改和软删除。画册先创建持久容器和标题，再在画廊页面从资源弹窗上传/选图，支持说明、排序、修改。三种表单复用原账号/资源/revision/审核服务。
- 关于正文初始源取自最新 main，统一生成静态 HTML 和运行时数据；新后台文案另经发布器生效，旧后台记录不覆盖站长新正文。CSDN、贡献图、年份和共同搭建说明保留。
